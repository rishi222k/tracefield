# Tracefield

A local studio for subject-bound constellation overlays: named points, a decorative web and an animated trace across a photograph. Part of the visual language of HUDs and fictional interface design (FUI).

This clean repository continues the studio developed in a private experiment. No photographs, reference screenshots, rendered checkpoints or private Git history are included. The library starts empty; add your own image through the agent workflow. The first public release is being prepared.

Node 24+, npm and git are required. Run `npm ci` and `npm start` to open the local studio at http://127.0.0.1:4318.
